# 烘豆小助手 Roasting Assistant

烘豆計時器暨記錄器。專為手機設計的單頁網頁 App，烘豆時一邊計時、一邊提醒操作、一邊記錄溫度與事件，烘完直接產出曲線圖與摘要，可匯出 JPG 或列印。

純 HTML／CSS／JavaScript，沒有後端、沒有建置工具，直接放到任何靜態網站空間（例如 GitHub Pages）就能使用，也能加到手機主畫面當 App 用。

👉 線上使用：<https://peihsinlin.github.io/coffee/ccdroastform/>

## 支援機型

| 機型 | 說明 |
| --- | --- |
| Mini500 | 依烘前重量自動帶入建議的入豆溫度、轉速、初始風門與火力提醒；火力為 0.1–3.0，風門從「全開、左5…中間…右5、全關」選擇；有「回溫點」「澎到最大」「第一聲」事件 |
| Fresh Roast SR800 | 熱風機；可匯入預設烘焙計劃（慢烘淺焙／中焙／快烘深焙），或自訂風速、火力提醒（1–9） |
| Fresh Roast SR540 | 同 SR800，有各自的預設烘焙計劃 |

## 功能

**烘豆前設定**

- 生豆資訊：烘焙師姓名、國家／地區（必填），以及莊園、公司、品種、處理法、價格、瑕疵率、含水率、密度、備註
- 豆量及環境：烘前重量、環境溫度（必填）
- 烘焙計劃與操作提醒，依機型不同：
  - **Mini500**：輸入烘前重量後，自動帶入入豆溫度、轉速、初始風門，以及回溫點、2:00、8:00 三筆火力提醒；另外固定帶入四筆風門提醒（澎到最大後 00:00 全開、00:50 左2、01:00 右2，一爆起後 00:50 全開）。都可以自行新增或刪除。風門提醒可以綁定事件，例如「澎到最大後 00:50 左2」。
  - **SR800／SR540**：選一條預設曲線匯入風速、火力提醒（會取代已設定的提醒），或自行新增。

**烘豆中**

- 計時器：每 30 秒跳出溫度輸入，前 3 秒有「嘟嘟嘟」預備音，第 30 秒「嗶」
- 操作提醒時間到時，以嗶聲加語音提示，需按確認才寫入紀錄；10 秒沒動作會自動寫入
- Mini500 按下「回溫點」後，計時與 30 秒節奏從 00:00 重新起算，火力、風門提醒也從這時開始生效
- 手動記溫：時間點以「按下去的當下」為準，輸入再久也不會讓時間點延後
- 可暫停／繼續計時，也可隨時手動調整風速、火力（Mini500 為風門、火力）
- 事件按鈕：一爆起、一爆止、二爆起、二爆止；Mini500 另有回溫點、澎到最大、第一聲
- 即時曲線圖、升溫率（RoR）與發展時間
- 事件時間軸表格：溫度、30 秒與 60 秒升溫、事件、風速／風門、火力
- 烘豆期間保持螢幕不休眠（支援的瀏覽器）

**烘完之後**

- 烘焙摘要：發展時間、發展百分比、發展期升溫、總升溫、總熱能、失重
- 填入烘後重量、烘焙度（豆／粗粉／細粉），自動算出粗粉差、細粉差
- 匯出 JPG（含曲線圖、生豆資訊、事件時間軸）
- 列印版面（白底，內容與 JPG 一致）

「總熱能」是豆溫曲線下面積（°C·分），只是方便比較不同烘焙的相對數值，不是物理上的熱量。Mini500 只計算回溫點之後的部分。

## 使用方式

1. 開啟網址，填寫生豆資訊、選擇烘豆機，並填好必填欄位
2. 確認烘焙計劃與操作提醒
3. 按「開始烘豆」，依畫面提示記錄溫度與事件
4. 烘完按「結束烘豆」（或頁面下方的「結束烘豆，查看結果」），輸入最後溫度
5. 填入烘後重量與烘焙度，匯出 JPG 或列印

## 加到手機主畫面

- **iPhone（Safari）**：開啟網址 → 分享按鈕 → 加入主畫面
- **Android（Chrome）**：開啟網址 → 右上角選單 → 安裝應用程式，或加入主畫面

加入後會全螢幕開啟，沒有網址列，網路不穩時也能開啟。

如果是從 LINE、Messenger 等 App 裡點開連結，畫面會提示改用手機瀏覽器開啟，以免提示音、匯出等功能無法使用。

## 注意事項

- 資料只存在當次的畫面中，**沒有儲存到瀏覽器或雲端**。重新整理或關閉頁面會清空，烘完請先匯出 JPG 或列印留存。
- iPhone 與部分 Android 手機在螢幕鎖定或切到背景後，系統可能暫停提示音與語音。烘豆時請保持螢幕開啟。
- 手機若開啟靜音，提示音量可能受影響。
- 溫度、時間與烘焙安全請以自己實際監控為準，本程式只是輔助工具。

## 更新注意事項

`index.html` 引用 `script.js` 與 `style.css` 時帶有 `?v=` 版本參數。修改這兩個檔案後，請把版本號加一，否則手機瀏覽器可能繼續使用舊的快取。

`service-worker.js` 採「先連網、離線才用快取」，平常改內容不用動它；只有新增或移除快取清單裡的檔案時，才需要調整裡面的快取名稱。
