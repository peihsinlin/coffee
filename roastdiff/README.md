# 焙比 RoastDiff

拖入 Nucleus Link 或 Kaffelogic Nano 7 的 Studio 軟體匯出的烘焙報告 PDF，自動讀出曲線、風扇、爆點、DTR、入豆溫度與曲線下面積（AUC），整理成表格，並把多支烘焙的豆溫、ROR、風扇轉速疊在一起比較。表格與曲線都可以下載成圖片。

所有解析都在使用者自己的瀏覽器內完成，PDF 不會上傳到任何地方。

## 支援的報告

| 項目 | 支援內容 |
|---|---|
| 機型 | Nucleus Link（Link Studio）、Kaffelogic Nano 7（Kaffelogic Studio） |
| 介面語言 | 繁體中文、簡體中文、英文 |
| 檔案 | Studio 軟體「匯出 PDF」產生的烘焙報告，可一次拖入多份，兩種機型可混用 |

`.nlog`／`.klog` 原始紀錄檔是加密格式，無法直接讀取，請先在 Studio 軟體匯出成 PDF。

## 使用方式

1. 開啟網頁，把一份或多份 PDF 拖進上方的框（或點一下選擇檔案）。
2. 在「表格欄位」勾選要顯示的欄位。
3. 視需要填寫手動欄位（淡色底的格子），例如風門策略、焙度、烘後重。
4. 在表格上方填日期與標題，用每列右側的 ↑ ↓ 調整順序。
5. 按「下載表格」「下載曲線」或「表格及曲線合併下載」存成 PNG。

## 表格欄位

預設顯示：機型、檔案、曲線編號、風門策略、DTR、風量設定、風扇調節、第一聲、實際一爆、預期一爆、下豆、AUC、烘後重(g)、豆焙度、細粉焙度及粉差。

預設隱藏（可勾選開啟）：建議DTR、風速、入豆溫、粗粉焙度及粉差、曲線設計者。

### 自動讀取

| 欄位 | 來源 |
|---|---|
| 機型、檔案、曲線編號、曲線設計者 | 報告文字 |
| DTR | 報告記錄的發展階段比例；沒有記錄一爆時，依預期一爆推估並註明 |
| 風扇調節 | 曲線設定中的 fan step（時間與調整比例） |
| 風速 | 風扇曲線圖：起始、一爆、下豆三個時間點的轉速 |
| 入豆溫 | 烘焙曲線圖上豆溫曲線的起點 |
| 實際一爆 | 報告有記錄一爆時自動帶入，也可手動輸入 |
| 預期一爆、下豆 | 報告文字（第一行時間、第二行溫度） |
| AUC | 以入豆溫度為基準，從入豆累加到下豆的豆溫曲線下面積（°C·min） |

### 手動輸入

| 欄位 | 輸入方式 |
|---|---|
| 風門策略 | 下拉選單 A / B / C / D |
| 建議DTR | 輸入範圍，例如 `10-12`，顯示為 `10-12%` |
| 風量設定 | − / + 每次調整 0.005，也可直接輸入 |
| 第一聲、實際一爆 | 輸入「時間 溫度」，例如 `6:40 203`，會分成兩行顯示 |
| 烘後重(g)、豆焙度、粗粉焙度、細粉焙度 | 輸入數字，自動取到小數一位 |

粉差會自動計算：粉差 = 粗粉焙度 − 豆焙度，細粉的粉差 = 細粉焙度 − 豆焙度。

手動填的值會記在使用者自己的瀏覽器（localStorage），下次載入同一個檔名會自動帶入。換瀏覽器或清除網站資料後需要重新填寫。

## 曲線比較

- 由上而下為豆溫、ROR、風扇轉速三張圖，共用同一條時間軸。
- 網格為正方形：每格 1 分鐘；豆溫每格 50°C、ROR 每格 20°C/min、風扇每格 50。
- 空心圓為一爆（虛線圓表示預期值），實心圓為下豆。
- 風扇轉速以報告中深藍色的基礎曲線為準；套用風扇調節後的曲線以同色淺色線畫出，下豆後的調節也會顯示。
- 滑鼠移到圖上（手機用手指滑），可在提示框看到每一份報告在該時間點的豆溫、ROR、風扇轉速與調節後轉速。

## 判讀方式與限制

報告的圖表在 PDF 中是圖片，曲線數值是讀取圖片像素換算而來：

- 座標軸刻度以字形比對辨識，並對齊圖上的格線。
- 依 Studio 圖表固定的線條顏色辨識各條曲線；實際曲線被設定曲線蓋住的段落，以設定曲線補上。
- 讀圖誤差約 ±1%（入豆溫度約 ±0.1°C）。

如果日後 Studio 軟體改變圖表配色或版面，判讀可能需要調整。
