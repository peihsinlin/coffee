焙比 RoastDiff

拖入 Nucleus Link 或 Kaffelogic Nano 7（Studio 軟體）匯出的烘焙報告 PDF（可一次多份，兩種機型可混用），自動讀出曲線、風扇、爆點、DTR、入豆溫度與曲線下面積（AUC），產生可下載的表格圖片。所有解析都在你的瀏覽器內完成。

拖曳 PDF 到這裡，或點一下選擇檔案 支援 Link Studio 與 Kaffelogic Studio 的報告格式，繁體中文、簡體中文或英文介面皆可

表欄位說明：

  • 欄位可依照主題及需求勾選/取消勾選。勾選則顯示，取消勾選則不顯示。
  • 欄位皆可手動輸入及修改。
  • 填寫烘前及烘後重後，會自動算出失重率＝（烘前重 − 烘後重）÷ 烘前重
  • 填寫豆焙度及粗/細粉焙度後，會自動計算粉差＝粗/細粉焙度 − 豆焙度。
  • 第一聲、實際一爆填「時間 溫度」（例如 6:40 203 或 0640 203，會分成兩行顯示；報告有記錄一爆時會自動帶入實際一爆）
  • 手動填的值會記在這台瀏覽器，下次載入同一個檔案會自動帶入。
  • 每列右側的 ↑ ↓ 可以調整順序。

曲線比較

由上而下：豆溫、ROR、風扇轉速，三張共用同一條時間軸。空心圓＝一爆（虛線圓為預期值），實心圓＝下豆。風扇轉速以報告中深藍色的曲線為準；報告裡較淺的藍線（套用風扇調節後）用同色較淺的線畫出。曲線若完全重疊會互相遮住，滑過圖表可在提示框看到每一份的數值。滑過圖表可看各時間點數值。
